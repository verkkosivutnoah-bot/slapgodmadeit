# Beat cover prompts (Gemini)

House style: urban night, one warm sodium streetlight, haze, deep blacks, subject small, empty space
low in frame. Ask for **square, 2000×2000 or larger**. Reject any image with letters in it.

Save each file as `web/public/covers/beats/<slug>.jpg` — the slug is the heading below.
Then tell Claude "covers dropped" and it will check sizes, names and deploy.
